Como subir no Coolify

  1. Crie um repositório no seu GitHub e envie este código para lá.
  2. No painel do Coolify, adicione um novo recurso do tipo **PostgreSQL** (banco de dados).
  3. Adicione uma nova aplicação conectando ao seu repositório GitHub.
  4. Nas configurações da aplicação no Coolify, adicione a variável de ambiente: 
    DATABASE_URL=postgresql://[usuario]:[senha]@[host]:[porta]/[banco]
    Dica: O Coolify permite vincular o banco diretamente, preenchendo essa variável automaticamente!
  5. O Coolify usará o `Dockerfile` incluído e fará o build e deploy. O banco será configurado e tabelas criadas automaticamente na inicialização!
